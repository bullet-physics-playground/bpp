# Euler's Gallery against theory: tests/harness.py theory (--slow for all).
#
# Each [Exhibit] runs as demo/WyomingWill/EulersGallery/report/ ran it for
# the physics-fidelity report (its dossiers/<Exhibit>.md: "Run used"), and
# what it prints is checked against the theory the dossier compares it
# with. Only rows whose number the exhibit prints are checked; the others
# (from CSV logs, other settings, or worked by hand) are listed as "not
# checked here". A tolerance is a few times the agreement the report
# found, so that a change to the physics fails while another machine's
# rounding does not. The syntax: class TheoryCheck in tests/harness.py.
#
# Exhibits that seed from the clock are given a seed, so that each run is
# the same.
