# Chapter 6 — Physicomimetics for Distributed Control of Mobile Aquatic Sensor Networks in Bioluminescent Environments

Authors: Christer Karlsson, Charles Lee Frey, Dimitri V. Zarzhitsky, Diana F. Spears, Edith A. Widder.
PDF pages 176–223 (book pp. 145–191). PDF page = book page + 31.

Application: a swarm of autonomous surface vehicles ("drones" = distributed roving ocean explorers) with
bathyphotometers maps bioluminescence potential (BP) of dinoflagellates. Two tasks (§6.2.2, PDF 180–182):
- **Max task (HAB monitoring)**: go from A to goal B through the field while finding/following the BP maximum
  (point source → plume tracing; non-point → map and track the moving maximum).
- **Min task (covert Navy insertion)**: scouts find the path of *minimum* bioluminescence from offshore to a
  shore goal; the team then follows the path. The swarm's **centroid track** is the proposed path.

Three stages: NetLogo simulator (§6.3) → Multi-Drone Simulator MDS in C++/Qt (§6.4) → hardware ASVs (§6.5).
No NetLogo model file name is given in the text (code listings 6.1–6.5 only).

## E6.1 Dinoflagellate chemical-field generator ("Run Dinos") — §6.3.1, PDF 183–188, Listings 6.1–6.2, Figs 6.4–6.5

What: builds a random static scalar field ("chemical" ∝ BP) the drones explore.
- Agents: `dinos` turtles, created at random positions (Listing 6.1 creates 250; experiments use 290/400/510;
  GUI slider "Number of Dinos" 0–500, default screenshot 280).
- Algorithm (StarLogo/NetLogo **Slime** model, Listing 6.2), repeated **100 ticks**:
  1. `diffuse chemical 1` (each patch shares 100 % of its chemical equally to its 8 neighbours);
  2. every patch: `chemical *= 0.995` (models chemical sinking below surface);
  3. colour `scale-color green chemical 0 6`;
  4. each dino: sniff patch ahead / right-ahead 45° / left-ahead 45° at distance 1, turn ±45° toward max
     (tie rules: right if right ≥ ahead and right ≥ left, else left if left ≥ ahead); then `rt random 40`,
     `lt random 40`, `fd 1`, deposit `chemical + 2` on its patch.
- After generation, the field is treated as **static** during the drone run (dinos much slower than drones, PDF 193).
- Environment classes (§6.3.7.1, PDF 200): **Low** avg density ≈ 2.0 (290 dinos), **Medium** ≈ 2.7 (400),
  **High** ≈ 3.5 (510). Avg density = sum of patch chemical / number of patches. 200 random seeds per class
  (seed slider 1–100 in GUI; experiments use 200 seeds via a wrapper).
- Result: clustered bright blobs (Fig. 6.5 / 6.8), aggregated by the slime-mold chemotaxis.
- Ambiguities: world size not stated (square NetLogo world; see note under E6.4 for an estimate). Listing 6.1
  sets `chemical 2` at dino creation then immediately zeroes all patches (no effect). Boundary: NetLogo default
  (probably wrapping torus for dino motion/diffusion) — porter decides.

**BPP notes**: Easy. Implement as a 2D grid field in Lua (diffuse-8, decay, slime-mold walkers) and draw it as
a coloured ground/water-surface texture or a grid of flat tiles (needs **scalar-field drawing** groundwork —
shared with Ch. 8–9 fluxotaxis and Ch. 11). Deterministic seeds per run needed for the paired comparisons.
★ 3D: generate a 3D BP volume (diffuse in 3D voxels, dinos in layers; BP typically peaks in a depth band) for
the AUV version; or advect the field with a current to make the "changing maximum" of a non-point HAB.

## E6.2 Physicomimetic ASV swarm with APO + goal force — §6.3.2–6.3.4, PDF 188–192, Listings 6.3–6.5

What: formation keeping + chemical gradient following (APO) + goal attraction; the core controller.
- Agents: `drones` NetLogo turtles (point particles, mass 1), 1–7 via slider (hexagon motivation), 3–18 in
  experiments (by code change). Start: fixed (deterministic) formation positions in the **upper right**, random
  headings, zero velocity. Goal: single stationary turtle in the **lower left** (Fig. 6.6).
- Force law (Listing 6.4), for every other drone within **r < 1.5 D**:
  - split Newtonian: F = G·m_i·m_j / r², clipped at FMAX; attractive if r > D, repulsive if r ≤ D.
  - **APO term** (same neighbours, constant magnitude apoF, along unit vector to neighbour):
    max task: repelled from neighbours with *lower* chemical than self, attracted to those with higher (or
    equal); min task (`minimum? = true`): the reverse. Code: if (min? and mine < theirs) or (max? and mine >
    theirs) → F −= apoF·Δ/r else F += apoF·Δ/r. Note ties count as attraction.
  - **Goal force** (Listing 6.5): constant magnitude goalF toward goal, **only if the drone has ≥1 neighbour**
    (`ncount > 0`); isolated drones stay still.
- Integration: v ← (1 − FR)·v; v += ΔT·F/m; position step ΔT·v; heading set from velocity.
- Sensing: each drone samples chemical only at its own patch and shares it with neighbours (no look-ahead).
- Mission success: first drone within the goal radius (text: **2 units**, PDF 198; Listing 6.5 uses r < 1 —
  inconsistency, use 2 for experiments). Time limit exists but was never hit.
- GUI parameter ranges (§6.3.5, PDF 193–195): Desired Separation D 2–10 (screens: 4); Force Maximum 1–5
  (screens: 1.0; theory assumes 1); Friction 0–1 (screens 0.50; **experiments 1.0**); Time Step (screens 0.50);
  Goal Force (screens 0.30); toggles Goal on/off and Min/Max. Monitors: "Goal Force Theory" (screen shows 0.2),
  Average Chemical Seen (screen 4187.85 at 1981 ticks, 7 drones, seed 79, 280 dinos).
- Listing 6.3 (shown first) has the APO sign reversed relative to Listing 6.4 (attracts toward lower-
  chemical neighbours) — treat Listing 6.4 as authoritative.

**BPP notes**: Easy as a 2D particle replica (reuse existing Ch.3 split-Newtonian particle code; add APO term,
goal force with ncount gate, centroid sensor). Medium for vehicles: use an **ASV model** = round holonomic
surface disc (see E6.7) that takes a force/velocity command — better than quadcopters since the hardware is
literally an X–Y particle. Needs: per-agent scalar sampling of the field, neighbour broadcast of samples
(range-limited comms), velocity/thrust commands. Decide world units ↔ metres (hardware hull 18″ ≈ 0.46 m;
D slider 2–10 units, "max 10 due to sensing hardware").

## E6.3 Balance-of-forces theory (bounds on goalF and apoF) — §6.3.6, PDF 196–198, Figs 6.9–6.10, Eqs 6.1–6.2

Closed-form predictions checkable by simulation:
- G from phase-transition theory (Eq. 3.4): **G ≈ 0.9·Fmax·D^p / (2√3)** to avoid clustering (p = 2 here).
  With Fmax = 1, D = 4: G ≈ 4.157.
- Cohesion bound (Fig. 6.9: three agents stuck, fourth pulled by goal): goalF < G/D^p ⇒
  **goalF < 0.9/(2√3) = 0.25981** (Eq. 6.1, Fmax = 1).
- No-stagnation bound (Fig. 6.10: drone b ahead in a hexagon; neighbours d (ahead, worse) at 0°, a and c at
  ±60° feel APO pushes; horizontal resultant apoF + 2·apoF/2 = 2·apoF must be < goalF):
  **apoF < 0.13** (Eq. 6.2).
- In the experiments goalF = **0.40**, deliberately exceeding Eq. 6.1 (footnote: ASVs in water unlikely to get
  stuck); friction 1.0 keeps formation intact; "on every run the swarm stays in formation and succeeds".

**BPP notes**: Easy. Sweep goalF and apoF in the 2D replica and show (a) fragmentation threshold near goalF ≈
G/D² and (b) stall threshold near 2·apoF ≈ goalF on a synthetic step field. Good batch-run validation case.
Ambiguity: the bound uses the force at exactly r = D, but the split law switches to repulsion at r ≤ D; also
the 0.9 factor comes from Ch. 3 — check against our existing Ch.3 G choice.

## E6.4 NetLogo experiments: Max-Agents, Min-Agents, Max-Ratio, Min-Ratio — §6.3.7, PDF 198–209, Figs 6.11–6.14

Design (PDF 198–201):
- Independent vars: **N ∈ {3, 6, 9, 12, 15, 18}** (ratio fixed 4.0); **ratio goalF/apoF ∈ {4.0, 20.0, 30.77,
  40.0}** from goalF = 0.40, apoF ∈ {0.10, 0.02, 0.013, 0.01} (N fixed 6). Friction 1.0. Not factorial.
- 3 environment classes × 200 seeds, same 200 environments for every configuration (paired).
- Metrics, all measured at the formation **centroid** (marked red each step, imagined bathyphotometer):
  Mean Total Chemical (sum over run of chemical at centroid patch), STD Chemical, Mean Peak Chemical,
  Mean Total Time (ticks to first drone within 2 of goal), STD Time.
- Hypotheses and results (curves read from figures; approximate):
  - **H1 (max: more agents ⇒ more chemical)** confirmed, Fig. 6.11 (ratio 4, apoF 0.10): Mean total chemical
    rises with N — Low ≈ 3500 (N=3) → 5200 (N=18); Medium ≈ 5100 → 7600; High ≈ 5500 → 9100.
  - **H2 (min: U-shaped, optimum interior)** confirmed, Fig. 6.12: small differences below N = 15, minimum at
    **N = 6** for all classes; Low ≈ 2500 flat → 3000 at 18; Medium ≈ 3250 (N=3), 3150 (N=6) → 4500 (18);
    High ≈ 4100, 4000 (N=6) → 4900 (18). Min-task totals much lower than max-task totals.
  - **H3 (more agents ⇒ longer time)** at ratio 4, Fig. 6.13 (both tasks, all classes): ≈1570 ticks (N=3) →
    ≈1750 (9–12) → ≈1900 (15) → 2100–2900 (18). Reason confirmed (H3.1): more meandering, not inertia.
  - At **ratio 40** (Fig. 6.14, max task; min task "nearly identical"): time *decreases* with N, with a bump
    at 12: ≈1433 (3), 1418 (6), 1396 (9), **1412 (12)**, 1388 (15), 1378 (18). Revised H3′: time grows with N
    only when ratio is low. H3.1.1: bigger formations hit the goal sooner because front perimeter agents start
    closer; H3.1.2: 12-agent initial layout is more concave toward goal.
  - Deterministic check with **no chemical**: goal reached in **1295 ticks (N=9), 1313 (N=12), 1292 (N=15)**
    (PDF 208). These exact numbers are a strong porting target (depend on world size, ΔT, start layout).
  - Max-Ratio / Min-Ratio, peak chemical, STDs, density classes: run but "not interesting"; no graphs. Informal
    hypothesis (denser env ⇒ more total & peak chemical) confirmed.
- Conclusions (PDF 209): max ⇒ low ratio + large swarm; min ⇒ low ratio + moderate swarm (task-specific
  optimum; too few = poor sampling, too many = can't "squeeze" through low-BP channels); speed ⇒ high ratio +
  large swarm unless formation concave toward goal (concavity may not matter if formation rotates).

**BPP notes**: Medium (needs a **batch-run harness**: seeds × classes × configs, headless, CSV output; 200 ×
3 × 10 configs × 2 tasks ≈ 12 000 runs — particles only). Particle replica first; the 1295/1313/1292 numbers
let one calibrate world size and step: with friction 1, each tick moves ≈ ΔT²·goalF = 0.25·0.4 = 0.1 units
(if ΔT = 0.5), i.e. ~130 units of travel, consistent with a ~100×100-patch world corner-to-corner — **this is
an inference; the porter must choose world size, ΔT and the hexagonal start layouts for N = 3…18**
("initial agent positions are deterministically set", not given). Then repeat with ASV dynamics (inertia,
thrust limits) to see whether H2's optimum N = 6 survives. ★ Run the min-task as a real "covert path": after the
scouts pass, fly a larger "team" vehicle along the recorded centroid track and integrate BP along it.

## E6.5 MDS: Multi-Drone Simulator (C++/Qt) — §6.4, PDF 210–218, Figs 6.15–6.17

Architecture/model features (an implementation spec rather than an experiment):
- Each drone subsystem (sensors, control, propulsion, comm, localization) is a separate Qt thread with its own
  emulated microcontroller clock; messages on an emulated data bus; drones may have different clock rates
  ⇒ **asynchronous** updates. Pseudo real-time: 1 s of Time Step = 1 s wall clock at 1× speed.
- Timing: control period = Time Step; **neighbour localisation updates at Time Step/2** (2 fixes per control
  decision); **environment/physics integration at Time Step/25**.
- Virtual (AP) friction separated from real fluid drag; true SI units (1 kg, 1 N ⇒ 1 m/s²); geo-referenced area.
- Comms: range-limited, TCP/IP-like, 32-bit IP per drone, 16-bit message IDs, time-indexed messages.
- Localisation: local-frame trilateration/multilateration (GPS ±3 m deemed too coarse) with user noise model.
- Environment sensor: queries field; control uses a **normalised** vector sum of formation and environment
  forces; GUI slider **Max Environment Force** sets relative magnitude.
- Control laws selectable at run time: **Hooke's spring, Lennard-Jones, split Newtonian**; hexagonal lattice
  (repel if too close, attract if too far).
- Propulsion: dual-propeller (VSP) thruster model, thrust in any direction; tracks generalised **"fuel"**
  consumption ∝ control effort.
- User-variable: number of drones, localisation range, comm range, noise type/level, force law + params, D,
  time step. Up to 4 metrics plotted live; logging.

## E6.7 Hardware ASV drone platform and tests — §6.5, PDF 218–222, Figs 6.19–6.21

- Hull: round PVC, ≈ **18″ diameter, 6″ deep**; sealed lead-acid batteries.
- Propulsion: **two counter-rotating Voith–Schneider propellers** (5 vertical blades each; constant rotor
  speed; cyclic pitch sets thrust direction, collective pitch + rpm sets magnitude) ⇒ holonomic X–Y thrust in any
  direction; second VSP cancels torque. Vehicle also has yaw freedom (not needed). No "forward" direction.
- Computer: ARM-9 on PC/104, Linux; magnetic compass, GPS; neighbour localisation by an RF **Hyperbolic
  Localization System** (4 antennas, TDOA of RF pings; HBOI + Textron, inspired by Ch. 10 acoustic/RF
  trilateration). Sensors: water temperature, salinity, bioluminescence.
- Fleet of **7** built; tested only under **remote control** in an HBOI test tank and Florida ponds; no
  autonomous swarm results reported.
- Long-term goal: low-cost **AUVs** for 3D underwater swarming (RF unavailable underwater ⇒ localisation and
  comms become hard).

**BPP notes**: Medium. New **ASV vehicle model**: cylinder 0.46 m × 0.15 m floating on a flat water plane
(buoyancy as spring + heave damping, or constrain to z = 0), horizontal thrust vector with magnitude limit and
first-order actuator lag (VSP pitch change), linear+quadratic hydrodynamic drag, yaw torque residual. Then run
E6.2/E6.4 with 7 ASVs (actual fleet size) on the same fields. ★ AUV version: neutrally buoyant body with 3D
holonomic thrust, acoustic-only comms (range/latency limits), 3D BP volume from E6.1-3D; tasks become "find BP
maximum layer" and "least-light 3D path" (submarine transit) — directly what the authors say comes next.

## Contradictions / additions to the existing plan ("bioluminescence with ASVs then AUVs (Ch. 6)")

- Confirms the plan, but the right vehicle is a **holonomic round ASV** (VSP "water helicopter"), not a
  boat with heading; it maps almost 1:1 to a point-mass-with-limits, so it can be done before quadcopters.
- The plan should include the **min (covert path) task** as well as max; the chapter's main quantitative
  results are the N-vs-chemical curves (H1 rising, H2 U-shape with optimum N = 6) and the time curves
  (H3 at ratio 4; negative slope + bump at 12 at ratio 40; deterministic 1295/1313/1292 ticks).
- The controller is **APO** (precursor of Ch. 18–19 APO) — share the implementation with the APO-from-altitude
  item; the theory bounds (goalF < 0.2598, apoF < 0.13) are cheap validation runs.
- Needs groundwork the plan doesn't list: scalar-field generator/drawing (slime-mold dinos), batch-run harness
  with seeds and paired environments, comms-range/localisation-noise/asynchronous-clock model (MDS), Hooke's
  law (MDS offers it; also appears in the plan's "Hooke's law formations").
- Ambiguities the porter must settle: world size, ΔT used in experiments, initial formation layouts for
  N = 3–18, success radius (2 vs 1), boundary handling, Listing 6.3 vs 6.4 APO sign.
