# Chapter 7 — Gas-Mimetic Swarms for Surveillance and Obstacle Avoidance

Author: Wesley Kerr. PDF pages 224–253 (book pp. 193–221). PDF page = book page + 31.

Task (§7.2, PDF 225–226): a swarm sweeps **once** down a long bounded corridor (land swath, building corridor,
tunnel) from the entrance to the goal end, maximising spatial coverage (longitudinal + lateral) and secondarily
minimising sweep time (temporal coverage). Too few robots to watch the corridor statically, so they must move.
Robots: simple, limited sensing, no GPS/maps/pheromones; only global info is the goal direction (e.g. light
sensor) and recognising the far end. Obstacles can be building-sized ⇒ obstructed perception.
Approach: **kinetic theory (KT)** — Lagrangian, collision-based, no potential energy/forces; robots are gas
particles in a **two-sided Couette flow** (both walls virtually moving toward the goal at Vwall).
Units below are inches (″) where the PDF lost the symbol (confirmed by Fig. 7.3 text "60″").
No NetLogo model is named; the simulator is the author's own (Ch. 4 holds a simplified NetLogo KT version).

## E7.1 KT robot controller (full algorithm) — §7.4, PDF 228–236, Listings 7.1–7.3, Figs 7.1–7.4

- Robot: holonomic, size **6″**, speed + heading; max speed **Vmax = 6″ per second**; position update
  p ← p + V·Δt, Δt chosen ~ mean collision time. Constant velocity unless a (virtual) collision occurs.
- Sensors: goal bearing (light sensor); **ring of 24 sonars every 15°, range 60″** (walls/obstacles); robot
  localisation (distance + bearing to neighbours, Ch. 10 RF+acoustic trilateration); RF comm of single floats.
- Constants (Listing 7.1): **T = 0.0030**, **v_mp = 1.11777**, **stdev = 0.79038** (ratio √2, so
  v_mp = √(2kT/m), σ = √(kT/m) with kT/m ≈ 0.6247 in sim units — i.e. k is NOT the real Boltzmann constant
  1.38e-23 the text quotes; porter should just use v_mp and σ).
- Step order (Listing 7.1): increment per-partner collision counters; read goal bearing, neighbours, sonars;
  if no robot directly in front → wall collisions; then robot collisions; new move = vector sum.
  Listing says `distance = max(sqrt(vx²+vy²), 6)` — almost certainly should be **min(…, 6)** (cap at Vmax).
- Repeat-collision suppression: same pair (robot–robot or robot–wall) not re-processed for a predetermined
  number of steps (number not given). Low-level routines prevent real physical contact.

**Robot–wall collision** (§7.4.1, Listing 7.2, Fig. 7.3):
- Triggered if sonar[0] (ahead) < SAFE or side sonars (90°/270°) < 2 (SAFE not given; text says obstacle points
  must be within **15″**).
- Wall orientation: among the sonars between −45° and +45°, take left-most and right-most hits within 15″,
  join them as a line segment; if the angle between that segment and the goal line < **ε** (user-defined,
  value not given), the wall is "Couette" (moving). All goal-parallel walls, including obstacle sides, are
  treated as moving walls.
- New velocity (wall frame): normal component **Vx = v_mp·√(−ln U(0,1))** (Rayleigh); tangential **Vy ~
  N(0, σ)**; rotated into the robot frame (β = goalBearing − 90° + atan2(Vy, Vx)); if Couette, add **Vwall**
  along the goal bearing. (Garcia uses a biased Maxwellian in 3D — footnote 3.)

**Robot–robot collision** (§7.4.2, Listing 7.3, Fig. 7.4):
- Collision zone: distance < **15″** (independent of whether they are actually approaching).
- V_cm = ½(V_A + V_B); relative speed Vr = |V_A − V_B|; random post-collision angle θ ~ U(0, 2π);
  V_r′ = Vr(cos θ, sin θ); V_A = V_cm + ½V_r′, V_B = V_cm − ½V_r′ (momentum and relative speed conserved).
  Robots exchange bearings (or one robot computes and sends speed/angle, or they share θ) to agree.
- Listing 7.3 draws cos θ = 1 − 2U and sin θ = +√(1 − cos²θ), i.e. only the upper half-plane (a 3D-isotropic
  formula reused in 2D) — porter should use θ ~ U(0, 2π) as the text says. *Corrected (FINDINGS F95):* the
  half-plane is made whole by the listing's own "choose the assignment of v1 and v2 so that it doesn't result in
  an actual collision", as Kerr's `KTRobot` does; what remains is cos θ uniform, which in 2D favours θ near 90°.
  In Kerr's 2004 gas the same draw, from the x axis, adds ~1.6 points to its hot gas (F93).
- All collision results within the zone are vector-summed.
- Termination: halts when a sufficient percentage of robots have completed the sweep (percentage not given;
  §7.11 says "all robots" reach goal, limit 150 000 steps).

World: corridor **1000″ × 5000″**, random obstacles (rectangles, triangles, circles in Fig. 7.2; obstacle
coverage 0–50 %), hundreds of robots in Fig. 7.2 starting at one end and diffusing toward the goal.

**BPP notes**: Easy as 2D particles (pure kinematics, no forces). Medium on vehicles: KT outputs a velocity
vector, so it needs **velocity commands** (or a waypoint p + V·Δt each AP tick) — constant-speed straight
legs suit quadcopters far better than the Newtonian law (no jitter, since nothing oscillates; but speed changes
are instantaneous ⇒ check the drone's response to frequent random heading changes). Needs: **simulated sonar
ring (24 ray casts, 60″)** and line-fit wall-orientation test, line-of-sight neighbour sensing, pair-collision
cooldown counters, pairwise agreement (shared θ) — in Lua all trivially available centrally, but implement it
locally to stay honest. Ground robot (6″) or quadcopter in a corridor/tunnel. Decide ε, SAFE, cooldown, Δt.
★ 3D: Couette **pipe/duct** (tunnel or urban canyon) with the floor/ceiling also treated as moving walls;
wall rebound uses Garcia's biased Maxwellian (normal Rayleigh, two tangential Gaussians); robot–robot θ
uniform on the sphere (cos θ = 1 − 2U and φ ~ U(0, 2π) — this is where Listing 7.3's formula actually belongs).

## E7.2 Experiment 1 (theory): spatial distribution at equilibrium — §7.6, PDF 239–240, Fig. 7.5

- Square container, **no goal/no wall motion**; robots start in a tight Gaussian blob and diffuse to
  equilibrium. Container divided into C grid cells; prediction: **N/C robots per cell** (uniform).
- N = 100…800 (8 values), obstacle densities 0, 10, 20, 30, 40, 50 %; 20 runs per setting; metric relative
  error = |theory − sim|/theory × 100.
- Result: relative error **< 10 %** for all obstacle densities (even 50 %); ≈ 10 % at N = 100 falling to
  ≈ 5–6 % from **N ≈ 300** on, all curves nearly coincident (Fig. 7.5).
- Ambiguous: container size, cell count C, equilibration time, how error is aggregated over cells (mean of
  per-cell errors?), how obstacle cells are excluded.

## E7.3 Experiment 2 (theory): average speed vs temperature — §7.7, PDF 240–241, Fig. 7.6

- Couette container with no goal and no wall movement; **300 robots**; equilibrium assumed after **1000 steps**.
  T varied **50–400 K** (8 values), 6 obstacle densities 0–50 %, 20 runs each.
- Prediction (2D Maxwell): **⟨V⟩ = ¼·√(8πkT/m)** (= √(πkT/2m)), m = 1.
- Result: relative error **< 2 %** at all T and obstacle densities (Fig. 7.6, curves flat on zero).
- Used in reverse to set T = 0.0030 from the desired robot speed (with Listing 7.1's σ, ⟨V⟩ ≈ 0.99 units/step).

## E7.4 Experiment 3 (theory): velocity distribution in one- and two-sided Couette — §7.8, PDF 241–243, Figs 7.7–7.8

- **One-sided Couette** (one wall moving): prediction **Vy(x) = Vwall·x/W** (linear profile). 300 robots,
  corridor split into **8 longitudinal subcorridors**; measure mean Vy per subcorridor; 8 wall speeds
  (Vwall = 1…8), 6 obstacle densities, 20 repeats.
- Fig. 7.7 relative error (approx.): 0 % obstacles ≈ 33 % at Vwall = 1 falling to ≈ 7 % at Vwall = 8
  (*corrected, F94:* the 0 % curve's points, read from its PostScript, are 35, 23, 20, 18, 16, 15 % at V = 1–6;
  it has none at 7–8; `ch07/README.md` has every figure's points);
  10 % ≈ 35 → 22 %; 20 % ≈ 53 → 37 %; 30 % ≈ 75 → 55 %; 40 % ≈ 100 → 88 %; 50 % ≈ 120 → 103 %.
  Cause: theory forbids backward moves; simulation has them, more with obstacles.
- Fig. 7.8 left (Vwall = 4, one-sided): linear profiles; 0 % obstacles ≈ 0.4 → 3.1 across subcorridors 1→8
  (theory 3.75 in the subcorridor next to the wall, never reached); slope decreases with obstacle density,
  still linear up to 30 %; 50 % nearly flat ≈ 0–0.7.
- Fig. 7.8 right (**two-sided**, both walls Vwall = 4): prediction **Vy = Vwall for all x**; measured flat
  profiles ≈ 3.5 (0 %), ≈ 3.4 (10–20 %), ≈ 3.0 (30 %), ≈ 2.6 (40 %), ≈ 1.7 (50 %).
- Conclusion: adding obstacles ≈ reducing Vwall; theory highly predictive without obstacles at high wall speed
  (errors < 20 %, §7.9).

**BPP notes (E7.2–E7.4)**: Easy, particles only, headless batch runs (8 × 6 × 20 = 960 runs each). These are
the cleanest "theory reproduced" targets in the chapter. Obstacles: random blocks at a given area fraction.
★ 3D: equilibrium uniform density in a box (N/C per voxel), ⟨V⟩ = √(8kT/πm) (3D Maxwell mean), Couette between
two moving plates with a free third axis, and pipe flow — all with closed forms, a natural "kinetic theory 3D"
validation set before putting it on drones.

## E7.5 Comparison controllers: Default and Ant — §7.10, PDF 244–246, Fig. 7.9

- **Default** (baseline): same robots but 8 moves at 45° increments; weighted random choice: continue same
  direction **80 %** if available; remaining 20 % split in thirds: **2/3 to "shadow" moves** (cells just
  downstream of an obstacle, Fig. 7.9B–C) if available; remaining 1/3 split: half to the goal direction, half
  evenly over all open moves. Weights sum to 1.
- **Ant** (Koenig, Szymanski & Liu, node-counting with pheromones): look N/E/S/W, move to the neighbour cell
  with the **minimum pheromone**, update (mark) the current cell, repeat. Guaranteed complete coverage; needs
  stigmergy (environment marks).
- All algorithms use the same speed magnitude for fairness.

## E7.6 Full coverage-task comparison: KT vs Default vs Ant — §7.11–7.13, PDF 246–251, Figs 7.10–7.13

Setup:
- Corridor **1000″ × 5000″**, measured on a **50 × 250 cell** grid (20″ cells). Metrics: **w** sweep time
  (steps until all robots reach the goal; limit **150 000**); **p_c** fraction of cells visited ≥ once;
  **p_s** same over "shadow" cells just downstream of obstacles (Fig. 7.10).
- Exp. 1: **25 robots**, random obstacles **0–40 %**; 5 corridors per obstacle %; 10 trials per corridor with
  random initial positions/orientations; mean ± 95 % CI.
- Exp. 2: **N = 5…30 robots**, obstacles **30 %**; same 5 × 10 protocol.

Results (approx. values read from figures):
- **Sweep time w** (Fig. 7.11): Exp. 1 — KT ≈ 10 000 steps at 0 % rising gradually to ≈ 50 000 at 40 %
  (escapes box-canyon "wells" by stochastic backward moves); Ant ≈ 60 000–65 000 flat; Default fastest
  (≈ 3 000–15 000) up to 30 %, then jumps to ≈ 100 000 (large CI) at 40 %. Exp. 2 — KT ≈ 15 000–22 000 roughly
  flat in N; Default ≈ 8 000 flat; Ant falls from ≈ 125 000 (N=5) to ≈ 58 000 (N=30) (only Ant speeds up
  with N, via stigmergy).
- **Total coverage p_c** (Fig. 7.12): Ant ≈ 100 % always. KT ≈ 77 % at 0 % obstacles, ≈ 89–90 % at 10–40 %
  (obstacles add lateral motion). Default ≈ 42–45 % regardless of obstacles. Exp. 2: KT ≈ 57 % (N=5) → ≈ 90 %
  (N=30), "close to Ant in roughly one-third the time"; Default ≈ 18 % → 50 %.
- **Shadow coverage p_s** (Fig. 7.13): Ant 100 %. KT ≈ 68 % (10 %) → 81 % (20 %) → ≈ 76–78 % (30–40 %),
  "roughly 80 %", emergent (nothing in KT targets shadows). Default ≈ 25–32 % ("roughly 20 %"). Exp. 2: KT ≈
  38 % (N=5) → ≈ 85 % (N=30); Default ≈ 10 % → 35 %.
- Conclusions: Ant best spatially but ~3× slower, needs pheromones, predictable individuals; KT excellent
  coverage, no pheromones, unpredictable individuals (stealth), graceful degradation with robot loss,
  better for multiple sweeps.

## Contradictions / additions to the existing plan ("kinetic theory 3D (Ch. 7)")

- Ch. 7 is entirely **2D**; 3D is our extension (only hint: footnote 3, Garcia's biased Maxwellian for 3D).
  Do the 2D replica first: three closed-form validations (uniform N/C, ⟨V⟩ = ¼√(8πkT/m), linear/flat Couette
  profiles) plus the KT/Default/Ant comparison — the plan does not mention the theory checks or the baselines.
- KT is **velocity-based with no forces** — unlike the Newtonian AP already ported, it should not jitter on
  quadcopters; good contrast case for Ch. 13.
- Needs groundwork not in the plan: simulated sonar ring + wall-orientation line fit, pairwise synchronised
  random collision angle (comm), collision cooldown, obstacle-density generator, coverage/shadow grid metrics,
  pheromone grid for the Ant baseline, batch runs.
- Code bugs to not copy: `max(...,6)` speed (should cap), Listing 7.3's cos θ = 1 − 2U (the 3D formula; its half-circle is made whole by its assignment, F95), Boltzmann constant
  1.38e-23 with m = 1 (inconsistent with v_mp = 1.11777 at T = 0.003).
- Overlaps Ch. 4 (simplified KT NetLogo) and Ch. 11 (uniform coverage) — share code.
